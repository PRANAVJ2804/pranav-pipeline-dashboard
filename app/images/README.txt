PRANAV DASHBOARD - IMAGES
Put this "images" folder next to index.php (public_html/pranav-dashboard/images).
You may DELETE any old .png files inside images/icons - they are no longer used.

images/icons/         -> 63 glossy 3D-style vector icons (.svg, sharp at any size).
                         To use your own artwork, save a file with the SAME name (e.g. university.svg).
images/universities/  -> your real university building photos, e.g. muj.jpg, smu.jpg, amity.jpg
